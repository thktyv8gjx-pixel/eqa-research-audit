# 3D-Mem 精读

核验日：2026-10-21。论文：[arXiv:2411.17735v5](https://arxiv.org/abs/2411.17735v5)，CVPR 2025；首次投稿为2024年，不能记成2025年首发。阅读文件：`papers/3dmem.pdf`，页码均为此23页PDF物理页。已读正文p1–8、补充p10–14；其余附录未逐项复核，未运行代码。

**论文原文——问题与方法。** 将逐帧历史压缩为按物体共视关系聚类的 Memory Snapshots，并保留 Frontier Snapshots 供主动探索；先用问题相关类别筛选，再由VLM检索、决策。依赖RGB-D、准确位姿、物体检测和VLM判断（p3–5）。研究对象包括主动EQA、情景记忆EQA和另一项导航任务，三者结果不可互换。

**论文原文——数据和指标。** 主动EQA使用OpenEQA的184题子集；p6表1报告GPT-4o配置的LLM-Match 52.6、LLM-Match SPL 42.0。p7说明未能回答时以盲GPT-4o答案补全，并令SPL为0。因此“答对”本身不是“探索得到支持证据”。p7的情景记忆结果使用另一输入权限，不能与主动导航分数直接相减。

**作者自述局限。** p10 §7.3：静态场景假设、检测器/VLM能力约束、准确位姿依赖，以及网络和VLM调用带来的延迟。p11 §9提到单层探索范围。不是本文提出者新发现的问题。

**失败证据。** p11 §8分类，p12图5–6：问题可有多个合理答案；即便选对快照，小目标/分辨率限制仍把香料容器认成烤面包机。p13图7–8给出检索错误、物体类别错误；p14图9是漏检导致相关信息未进入记忆、最终耗尽步数。已看p12渲染图 `papers/figures/3dmem_failure_p12.png`；失败图不是本轮复现实验。

**公开代码/数据。** [官方仓库](https://github.com/UMass-Embodied-AGI/3D-Mem)，静态树快照提交 `f445e0828a2c5d5845ccdbd0992fc5eed871d19a`，存在运行入口和 `data/aeqa_questions-184.json`。完整HM3D场景需遵守原数据许可，未下载。只核验源码与标注公开，未证明整套环境能在4060运行。

**我的解释/待验证。** 可研究“原始历史中已有证据，却被检测/压缩/检索链丢失”这一可定位失效；必须先区分没拍到、拍到没存入、存入没取出、取出仍认错。最近邻包括[GraphEQA](https://arxiv.org/abs/2412.14480)、[MemoryEQA](https://arxiv.org/abs/2505.13948)、[Pred-EQA](https://github.com/yuanrr/Pred-EQA)、[GSMem](https://arxiv.org/abs/2603.19137)，已经压缩了“增加记忆”的新颖空间。简单的均匀/多样性帧回退若足够，则复杂机制应被淘汰。
